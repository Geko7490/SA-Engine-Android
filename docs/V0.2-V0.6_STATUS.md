# SA Engine Mobile — V0.2–V0.6 implementation and verification

## V0.2: GitHub package catalogue — implemented, unit-tested
- Reads GitHub Releases API for `Geko7490/SA-Engine-Android`.
- Supports private repository access via an optional fine-grained read-only token entered by the user. Token is kept only in the current activity's memory; it is never shipped in the APK or saved to preferences.
- Displays release tag, notes, size, prerelease status and only explicitly declared Android minimum when available.
- Recognizes `SAEngineGame-*.apk` as game engines; labels `launcher-dev` `app-debug.apk` separately as a launcher test APK, **not a playable game**.
- Only lists release assets with an API-provided SHA-256 digest and an approved GitHub API asset URL.

## V0.3: Download manager — implemented, Android APK compiled
- HTTPS only, approved GitHub storage redirection destinations.
- Download progress, speed, ETA, cancel and `.part` restart-resume.
- Range response checks and file-size limits.
- Complete SHA-256 verification before moving a download into the verified cache.
- Cancelling the download preserves the partial file for the next attempt.
- Does not use an Android foreground service yet; closing the app cancels active downloads, which can be resumed when reopened.

## V0.4: APK installer — implemented, Android APK compiled
- Rejects non-engine packages, unsigned/uninspectable archives and unsupported Android SDK versions.
- Compares signing certificate digest to a previously trusted certificate and the installed game package. First trust requires an explicit user confirmation.
- Rejects downgrades.
- Uses scoped FileProvider, `REQUEST_INSTALL_PACKAGES` and the Android system installer.
- The Android OS still performs final APK signature verification; the user must approve installation.
- **Important:** The development APK is signed using an ephemeral GitHub Actions debug signing certificate. A later build can have a different certificate, making in-place updates impossible. Do not uninstall an installed launcher without backing up your GTA SA game files; uninstall may delete its app-specific data. Configure stable signing before any production distribution.

## V0.5: Launcher and game-file bridge — implemented as a cross-app contract
- Launcher detects `com.geko7490.saenginegame` and opens its start Activity when game data is present.
- Passes FPS and quality via explicit Intent extras.
- Protected, read-only ContentProvider in the launcher exposes user-imported files to the installed game. It checks that the caller UID owns the engine package, rejects traversal and supports paginated directory enumeration.
- The Unity Android `.androidlib` plugin reads from this provider into the game's own `persistentDataPath/GTASA` before game asset loading. The original Loader coroutine is patched to await completion.
- Java source and the C# overlay compile in CI, but **real cross-application transfer and game startup have not been validated on an Android device**.

## V0.6: Playable Unity game — code prepared, genuine build blocked
- Target engine: SanAndreasUnity, pinned upstream revision from `upstream.lock`, MIT licensed.
- Unity 2020.3.26f1, Android ARM64 + IL2CPP, engine package `com.geko7490.saenginegame`.
- Automated workflow `.github/workflows/unity-game-apk.yml` checks for Unity activation secrets and builds/publishes `SAEngineGame-0.6-dev.apk` only if activation is configured.
- As of 2026-11-19 the workflow's activation gate passed but the actual Unity game APK build was skipped because no Unity activation credentials were configured.
- **No GTA SA game APK has been produced or tested, and no FPS increase is verified.**

## How to test the latest launcher APK
Download from the private repo: [launcher-dev release](https://github.com/Geko7490/SA-Engine-Android/releases/tag/launcher-dev). The GitHub Release must be inspected after Actions succeeds; it updates when CI publishes.

1. Install the Android launcher (back up game data before changing a debug-signed version).
2. Open **GitHub Deposundan Kur** and enter a token restricted to this repository with Contents (read-only) permission. The app never embeds an account token.
3. Load releases. The existing `launcher-dev` package is labeled as a launcher preview, not the game engine.
4. Select it to exercise the resumable SHA-256 download. It will not be offered as a playable engine installer.
5. Once a **real** `SAEngineGame-*.apk` release has been built and published, the same UI will validate its signature, request installation and expose the game launch button if the user imported their own legally obtained GTA SA PC files.

## Important limits
- The launcher is not the GTA SA game, and does not bundle Rockstar assets.
- The exact gameplay experience cannot be verified without a compiled Unity APK, legally obtained game files and testing on Android hardware.
- The initial engine bridge copies the imported game files into the game's own app-specific data, so enough free storage is required for both copies.
- A stable signing certificate must be configured before distributing engine updates; without this, Android will reject in-place upgrades.
